- http server config is setup in a struct, and if TLS cert is created, ListenAndServe (w/ TLS for https) method is used to start server. 
- A TLS cert provides info that the server was identified, encrypted and has integrity. 
- The cert itself contains a public key, CA signature and a domain. The private key stays on the server.

Syntax:
- import "net/http"
- serv := &http.Server{
	- Addr: ...
	- Handler: ...
	- ErrorLog: ...
	- TLSConfig: ...
	- IdleTimeout: ...
	  ReadTimeout: ... 
	- WriteTimeout: ...
- }
- err := serv.ListenAndServeTLS(".../cert.pem", ".../key.pem")
